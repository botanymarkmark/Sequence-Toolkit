Sequence Toolkit is a lightweight, dependency-free Windows desktop application that consolidates routine, error-prone sequence data curation into one graphical interface. It ships as a self-contained 10 MB executable: no Python, packages or command line required.

It covers four areas. Merge / convert combines FASTA and GenBank files into one output file, or, per file, converts each input file into its own output file, turning a directory of GenBank records into a matching set of FASTA files. Formats are recognised from content rather than extension, so inconsistently named files are handled correctly. Rename / split rewrites sequence headers by accession number, species name, or accession_species (spaces become underscores); it can also split records into individual files or rename files on disk. Search and batch download queries NCBI Nucleotide by species or genus, filters by length, completeness and RefSeq, and retrieves selected records. Download by accession accepts pasted accessions, a text file, or accessions extracted from existing sequence files. Results can be exported as accession lists in plain text or CSV.

Data integrity is a first-class concern. GenBank records keep their original text block, so FEATURES annotations survive merging byte for byte; unassembled CONTIG records are reported, not silently dropped; and no output is overwritten unannounced: identical files are skipped, differing ones get a numeric suffix. Serial numbers are added only when rendered names would otherwise collide. Downloads obey NCBI rate limits, retry transient failures, support an HTTP proxy, and continue past failures.

Every run writes a plain-text log plus, for records that cannot be interpreted reliably, an exception list giving file, line and final name. It targets researchers assembling genome-scale datasets, such as chloroplast genomes or barcodes for phylogenetics, who would otherwise script these steps. The code is organised in layered modules with 442 automated tests, and released under the MIT licence.
